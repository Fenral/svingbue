# Phase 2 onboarding usability check

Status: awaiting moderated sessions

This is the human acceptance gate for the final Phase 2 Definition of Done.
Automated tests must remain green, but they cannot prove that a new golfer
understands the flow without help.

## Pass rule

- At least 8 of 10 first-time participants reach the model result without help.
- Median time from the first onboarding screen to the visible result is 90
  seconds or less.
- A hint, explanation of a control, or instruction to scroll counts as help.

## Session setup

1. Use a supported phone or the 375x812 browser viewport.
2. Clear `sa.v1.context` before each participant.
3. Read only: “Use this app to understand one golf shot. Think aloud.”
4. Start timing when `See why it flew.` is visible.
5. Stop timing when `Here’s the relationship.` and the result table are visible.
6. Do not teach the product during the timed attempt. Record the first point of
   hesitation and any help given.
