Where the ball finishes

Face angle decides it; club path barely argues. Sweep both from 4° closed to 4° open and hold everything else fixed, and each degree of face moves the finish 4.5 yd — while each degree of path moves it only 1.5 yd, in the opposite direction. Face is 3.0× stronger and opposite in sign, so the shots that finish near the target line run in a shallow diagonal rather than straight down the square-face column: 2° closed against a 4° out-to-in path still finishes 3.0 yd left, and 2° open against a 4° in-to-out path finishes the same distance right. Square face with a neutral path is the only dead-straight shot in the grid.

The worst misses sit in opposite corners, not at the edges: 4° closed against a 4° in-to-out path is 23.7 yd left, and its mirror is the same distance right. Curve comes only from the gap between face and path — where they match, along the leading diagonal, the ball never bends, it just starts offline and stays there, which is why 4° closed with a 4° out-to-in path is a dead-straight Pull finishing 12.0 yd left. Every degree of gap adds roughly 2.2–2.3 yd of curve. Carry moves 1.2 yd across all 25 shots. The whole cost is sideways.

How these numbers were made

All 25 cells re-derived from impact-flight.js solveFlight in impact-flight.js via outputs/agent-scan/gen-face-path-outcome-matrix.mjs. No figure on this page is transcribed; the page itself is generated from that run. Exact sensitivities: +4.521 yd per degree of face, -1.513 yd per degree of path.

The mark under each value is a scaled reading, not a measurement: it places the finish on a shared ±25 yd track shown at identical width in every cell, so --x = 50% + offline/25 × 50%. The widest miss in the grid is 23.7 yd, so nothing is clipped. The number above the mark is the truth; the mark exists so the 3.0× step between rows and the small step between columns are visible at a glance.

Aero validity: PREMIUM_TOUR_CLASS_AERO validity envelope: every cell is extrapolated (spin parameter above ceiling for a 7-iron). Informational, not a blocker.
